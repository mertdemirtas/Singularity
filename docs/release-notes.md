## Singularity 0.1.1

- Installed extensions have their own icons in the sidebar. Right-click an icon to open its settings.
- Opening an extension view starts its extension, including views that depend on setup conditions.
- Closed or hidden views can be reopened. Views awaiting setup show guidance instead of an empty pane.
- Git workspace improvements include branch graphs, clearer history diffs, resizable panes, and confirmations for sensitive operations.
- Resolve merge conflicts with full-size code views, selectable changes, and revisable Current, Incoming, or Both choices. Applied choices are highlighted and support Undo and Redo.
- GitHub sign-in persists across restarts. Repository creation and publishing are available from the Git workspace.
- Faster startup and improved handling of large files and projects.
- The integrated browser uses Google search, offers recent pages, and avoids duplicate inspector windows.
- Installation and setup documentation is shorter and easier to follow.

See [installation and updates](https://github.com/mertdemirtas/Singularity/blob/main/docs/releases.md) for downloads and update instructions.
