## Singularity 0.1.1

- Installed extensions have their own icons in the sidebar. Right-click an icon to open its settings.
- Opening an extension view starts its extension, including views that depend on setup conditions.
- Closed or hidden views can be reopened. Views awaiting setup show guidance instead of an empty pane.
- Installation and setup documentation is shorter and easier to follow.

See [installation and updates](https://github.com/mertdemirtas/Singularity/blob/main/docs/releases.md) for downloads and update instructions.
